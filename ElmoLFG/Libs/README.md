# Bundled libraries

These unmodified library files were copied from the locally installed Questie addon. Leatrix Plus uses the same library names and revisions for its minimap button.

- LibStub, revision 2; public domain, credits retained in the source header.
- CallbackHandler-1.0, revision 8.
- LibDataBroker-1.1, revision 4.
- LibDBIcon-1.0, revision 56.

They load in the order listed above, before ElmoLFG's own files. LibStub reuses an existing library of the same or a newer revision when another addon has already loaded it.
